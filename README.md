# Raspberry PI Book Lessons (and testing)
Repository contains a set of Lesson plans derived from the book Mastering Raspberry Pi Programming with Sensor Development Kits by Zhu Linpu Mao. This repository aims to recreate projects, as well as act as a grounds for me to test sensor modules and different iterations of the lessons.

Much of these folders (specifically ones on the initial commit) were started much prior, around early 2025, and were written and tested directly from the raspberry pi's local desktop supported OS, using the built in IDE Thonny. Later, tests were primarily conducted by running a jupyter lab IDE on Raspberry pi and SSH port forwarding to laptop.
